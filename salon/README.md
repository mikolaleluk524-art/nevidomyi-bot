# «Магія краси» — застосунок салону (PWA)

Сайт-застосунок, який клієнтки відкривають з QR-коду і додають на головний екран телефону (без App Store / Google Play).

**Для клієнток** (`/`): прайс, вільні вікна і запис, передоплата (monobank), нагадування push за добу і за 2 год,
карта з маршрутом і покроковими фото «як дійти до кабінету», роботи, сертифікати, відгуки,
бонуси (кешбек, «приведи подругу», знижка на день народження), лист очікування «повідомте, якщо звільниться», додавання в календар.

**Для майстра** (`/admin`): записи по днях, ручний запис, «прийшла / не прийшла / скасувати» (з автоповерненням передоплати),
графік і відпустки, послуги й ціни, фото, модерація відгуків, клієнтки з нотатками і бонусами, push-розсилки,
налаштування, QR-постери для дверей / підʼїздів / зупинок зі статистикою, звідки приходять клієнтки.

## Запуск

```bash
npm install
npm run dev        # http://localhost:8080, дані в ./data
```

## Railway

Окремий сервіс з **Root Directory = `salon`**, команда старту `npm start`, том (Volume) змонтувати в `/data`.

| Змінна | Що це |
|---|---|
| `DATA_DIR=/data` | база й фото на томі (обовʼязково, інакше дані зникнуть після деплою) |
| `MONO_TOKEN` | токен еквайрингу monobank (web.monobank.ua → Еквайринг). Без нього — тестова оплата |
| `ADMIN_PASSWORD` | пароль кабінету. Якщо не задано — створюється при першому вході в `/admin` |
| `TG_BOT_TOKEN`, `TG_CHAT_ID` | дублювати нові записи власниці в Telegram (необовʼязково) |
| `PUBLIC_URL` | власний домен, якщо підключено (інакше береться домен Railway) |

Ключі для push (VAPID) створюються автоматично і зберігаються в базі.

**iPhone:** push-сповіщення працюють лише після «Поділитися → На початковий екран» (iOS 16.4+); застосунок сам підказує це клієнтці.
